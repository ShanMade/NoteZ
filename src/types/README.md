# TypeScript Type Definitions (`src/types`)

This directory maintains strict TypeScript interfaces and data contracts utilized across both client and server layers.

---

## 📐 Type Definitions

- **`notez.ts`**:
  - Core block definitions (`BlockType`, `BlockProps`, `NoteBlock`, `NotePage`, `FontStyle`).
- **`workspace.ts`**:
  - Document models (`WorkspaceDocument`, `WorkspaceVersion`), view identifiers (`WorkspaceView`), user records (`WorkspaceUser`), and provider status indicators.
- **`ai.ts`**:
  - AI chat schemas (`AiChatMessage`, `AiToolCall`, `AiProposal`, `AiRunRecord`), prompt parameters, and structured JSON output formats.
